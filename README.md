# InventoryUI

A MelonLoader mod that provides a UI for InventoryFramework.

## Features

- **Hotbar** displays the first 9 items in the player's inventory. Select slots with keys 1–9.
- **Item label** shows the selected item's name above the hotbar, fading out after a moment.
- **Item picker** press E to open a grid of all registered items. Click any item to pick it up in your cursor, click a slot to add it to the inventory.
- **Search** Search items to find one quickly
- **Arrangement** You can rearrange items in your hotbar however you want

## Requirements

- [MelonLoader](https://melonwiki.xyz)
- [InventoryFramework](https://github.com/Gameknight963/InventoryFramework)
- DOTween
